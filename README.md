# c-practice

C 语言学习练习代码。

大一在读，2026 年秋开始学 C。这里按目录存放每节课的练习程序，
目标是把从 `printf` 到指针、结构体、文件操作这一路的成长过程完整留下来。

## 目录结构

| 目录 | 内容 |
| --- | --- |
| `C/` | C 语言练习程序 |

## 环境

- 编辑器：VS Code
- 编译器：MinGW-w64（gcc 15.2.0）
- 编译命令：`gcc xxx.c -o xxx.exe`

## 说明

仓库只保存源码。编译产物（`*.exe`、`*.o`）和编辑器本机配置（`.vscode/`）已在 `.gitignore` 中忽略。
